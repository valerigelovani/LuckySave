# LuckySave

LuckySave is a bank-backed rotating savings product, prototyped as a complete, demo-ready Angular
front-end. A fixed-size group of members each contribute the same amount every month; the pooled
contribution becomes that month's prize pot, and one eligible member is chosen at random to receive
it. Every member can win once — after that they're excluded from future draws, but keep
contributing until the circle completes. If someone misses a payment, the bank covers it instantly
and a loan record tracks the balance until it's repaid.

This is a front-end-only MVP: there is no backend. All data is generated by an in-memory mock store
seeded with a realistic scenario and persisted to `localStorage`, so the demo survives a page
refresh.

## Getting started

```bash
npm install
npm start   # ng serve
```

Then open `http://localhost:4200`. No further setup, environment variables, or backend is required.

## What's included

- **Dashboard** — the current group's status, progress, prize pot, payment/eligibility state, and
  primary actions (Pay now / View group / Start draw / Join another group).
- **My Group** — full member roster with payment and eligibility status, history of winners, and an
  activity feed.
- **Draw** — the monthly draw experience: eligible members, a fairness explainer, a multi-second
  spin animation, and a confetti winner reveal.
- **History** — a monthly summary plus a filterable activity timeline (draws, payments, bank
  coverage, membership).
- **Create Group** — a validated form with a live preview of the group being created.
- **Join Group** — browse open groups with seats remaining and join instantly.
- **Loan Coverage** — outstanding and repaid bank-covered loans, plus a way to simulate a missed
  payment and see bank coverage kick in live.
- **Profile** — the current user's contributions, winnings, draws, payments, and participation
  history across every group they belong to.

## Language & currency

The app defaults to Georgian (ქართული) with Lari (₾) currency, and can be switched to English
(USD) from the toggle in the sidebar/top bar. The choice persists in `localStorage`. All interface
copy — navigation, statuses, forms, toasts, and the generated activity timeline — is fully bilingual
via a small signal-based `I18nService`; group and member names are treated as user content and are
not translated when switching languages, the same way a real banking app wouldn't retranslate an
account nickname.

## Architecture

```
src/app/
  core/            models, constants, seed data, and framework-free utilities
  services/        signal-based store + business-logic services (group, payment, draw, loan, toast)
  shared/          reusable UI components, pipes, and view helpers
  features/        one folder per routed page
```

State lives in a single `StoreService` built on Angular signals. Feature services
(`GroupService`, `PaymentService`, `DrawService`, `LoanService`) contain the business rules —
one win per member, bank coverage on a missed payment, draw eligibility — and mutate the store
immutably. A `StorageService` effect persists the whole state to `localStorage` on every change.

## Tech stack

Angular 20 (standalone components, signals, the new control-flow syntax), Angular Material 3
(themed with a custom brand palette), SCSS design tokens, and no other UI kit.
